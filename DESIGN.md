# Personal Website Color Palette Design

This document establishes the color architecture for the personal website using the **60:30:10 rule**. This distribution balance ensures high visual harmony while maintaining an ultra-minimalistic aesthetic.

## Color Proportions Rule
*   **60% Dominant Color:** Primary canvas and layout backgrounds.
*   **30% Secondary Color:** Structural elements, cards, sidebars, and body text.
*   **10% Accent Color:** Call-to-action (CTA) triggers, focus indicators, and interactive links.

---

## Dark Mode Scheme
Designed for a sleek, modern, and tech-inspired portfolio experience.

### Palette Breakdown
*   **Dominant (60%):** `#121212` 
    *   *Role:* Main page background.
    *   *Visual:* Rich, deep charcoal. Reduces eye strain.
*   **Secondary (30%):** `#E0E0E0`
    *   *Role:* Primary typography and container outlines.
    *   *Visual:* Soft off-white. Offers high readability without glare.
*   **Accent (10%):** `#00FF85`
    *   *Role:* Action items, active navigation links, and button fills.
    *   *Visual:* Electric mint. Provides a striking minimalist contrast.

---

## Light Mode Scheme
Designed for a crisp, airy, and professional editorial style.

### Palette Breakdown
*   **Dominant (60%):** `#F8F9FA`
    *   *Role:* Main page background.
    *   *Visual:* Clean, bright off-white. Avoids stark monitor glare.
*   **Secondary (30%):** `#212529`
    *   *Role:* Primary typography, iconography, and section dividers.
    *   *Visual:* Dark slate. Ensures maximum accessibility and contrast.
*   **Accent (10%):** `#2563EB`
    *   *Role:* Interactive targets, key buttons, and notification dots.
    *   *Visual:* Cobalt blue. Creates an immediate, trustworthy focal point.

---

## Minimalist Implementation Guidelines
1.  **Keep Borders Invisible:** Avoid heavy solid borders; let whitespace create the layout boundaries.
2.  **Use Accent Sparingly:** Do not use the 10% accent color on non-clickable decorative items.
3.  **Contrast Compliance:** Ensure typography weights are thick enough to meet WCAG AA legibility standards against the 60% background.
